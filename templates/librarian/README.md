# templates/librarian/

Templates for the Obsidian Librarian system. Used by librarian scripts to create new files with consistent structure.

## Templates

- `source_metadata.template.json` — JSON metadata for each ingested source
- `source_summary.template.md` — markdown summary of a source
- `concept_card.template.md` — concept article with frontmatter
- `identity_observation.template.md` — identity-related observation
- `aesthetic_observation.template.md` — aesthetic observation (voice/visual/music)
- `proposed_patch.template.md` — proposed change to an existing file
- `session_report.template.md` — report from a librarian session
- `health_check.template.md` — health check report
- `link_entry.template.md` — URL/link entry
- `playlist_entry.template.md` — playlist entry
