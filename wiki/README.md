# wiki/

The compiled knowledge base for the Rupture System. Obsidian-compatible markdown wiki.

## Structure

- `identity/` — Yuwas Maway identity observations and proposed updates to SOUL.md, STYLE.md
- `aesthetics/` — voice, visual, and music observations and proposed style bible updates
- `theory/` — concept cards, source summaries, algorithm dependency maps
- `social/` — social media identity preparation and proposed strategy updates
- `outputs/` — session reports, generated drafts, filed outputs

## How it works

The librarian compiles raw sources from `inbox/` into this wiki. Everything here is a proposal, summary, or index — not a primary source. The wiki grows over time as more sources are ingested and processed.

All files use Obsidian-compatible markdown with YAML frontmatter, relative links, and internal wiki links where appropriate.
