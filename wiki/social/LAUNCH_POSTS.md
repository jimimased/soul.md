## Post 4 — Face Grid (Instagram + Threads cross-post)

**Day 7. Second face grid with expanded caption.**

**Image:** ComfyUI_00054_.png (face grid with green/red/amber/grey variations — the multicolour grid, not magenta-dominant)
**Aspect:** 4:5 portrait
**Instagram caption:**
```
face grid 054. the face is a dataset.
```

**Threads cross-post (expanded):**
```
face grid 054.

the same face through twenty filters. green, red, amber, grey, desaturated. each cell is a different hypothesis about who this person is.

this is what facial recognition training data looks like if you strip the pretence of objectivity. every frame is an interpretation. every interpretation is a bias. the grid doesn't lie about this — it shows you all the versions at once.

the face is a dataset, not a portrait.
```

**Alt text:** Vertical grid of twenty portrait fragments arranged in five rows of four. The same face appears in each cell under different colour treatments — green, red, amber, grey, and desaturated — with visible halftone dot texture and scan-line artifacts throughout.

**Notes:** This is the first post that shows the Threads voice at length. The expanded caption demonstrates the accrete-then-rupture pattern and the transition from visual description to structural analysis.
