# Theory Corpus

This folder is the conceptual substrate of the system.
It stores the mathematical, philosophical, social, political, AI, cultural, and media-theory sources that the agent uses to build algorithms, metaphors, ethics, and product logic.

It is not a folder for random PDFs.
Every source should have metadata:
* title
* author
* year
* link
* source type
* why it matters
* related system files
* key concepts
* allowed use
* citation requirement
