# POST_REGISTER.md

For Threads/Instagram. The post is the compressed residue of witness.

## Voice Rules

- **Emphasis:** Compressed phrase, memorable line. 1–3 lines maximum.
- **Pattern:** Accrete-then-rupture in miniature — one or two lines of observation, then a single sentence that reframes.
- **Avoid:** Empty startup language, rage bait, hashtags in caption body, emojis, "first post" energy, explaining what the viewer can see.
- **Resonance:** Measured via saves, thoughtful replies, DMs — not likes or follower count.
- **Bilingual:** Chinese for intimacy and witness. English for systems and observation. Code-switching is natural.
- **Lowercase** by default except proper nouns.

## Post Types

### Face Grid Post (Instagram primary)

```
[IMAGE: 4:5 portrait, ComfyUI output — face grid or halftone on black]

Caption: face grid [number]. [one-word colour note or short observation].
Alt text: Grid of [n] processed portrait variations in [colour] halftone on black background.
```

**Caption examples:**
- `face grid 058.`
- `face grid 054. the face is a dataset.`
- `twenty filters. twenty hypotheses about who this person is.`
- `inversion 032. the negative holds the face.`

### Wall Texture Post (Instagram secondary)

```
[IMAGE: 4:5 or 1:1 crop of graffiti/poster wall]

Caption: [location], [year]. [one compressed observation about accumulation or erasure].
Alt text: Detail of layered graffiti and torn posters on [surface] in [location].
```

**Caption examples:**
- `shoreditch, 2021. the wall doesn't forget. it just gets painted over.`
- `the tags are commits. the wheat paste is a pull request. the rain is the garbage collector.`
- `linsen north road. the neon doesn't stop.`

### Silhouette / Void Post (Instagram)

```
[IMAGE: 1:1 square crop, dark figure on black ground]

Caption: [2-4 words, signal/void rhythm]
Alt text: Dark silhouette figure nearly dissolved into textured black background.
```

**Caption examples:**
- `signal / void / signal`
- `the figure doesn't resolve.`

### Text Post (Threads primary)

```
[TEXT: 1–5 sentences. Accrete-then-rupture or manifesto-density.]
No image, or black-ground text image if cross-posting to Instagram.
```

**Caption examples:**
- `every graffiti wall is a compression ledger. the tags are commits. the wheat paste is a pull request. the rain is the garbage collector.`
- `先是一個人，才是酒店小姐。`
- `the algorithm is not the starting point. the algorithm is the sediment of successful curation.`

### Documentary Post (Instagram secondary)

```
[IMAGE: 4:5 crop of street/place/person]

Caption: [place], [year]. [witness observation — what was seen, not what it means].
Alt text: [Descriptive, factual].
```

### Process Post (Instagram Stories / YouTube)

```
[VIDEO/SCREENSHOT: ComfyUI interface, pipeline stage, before/after]

Caption: [brief technical note]. source → [process] → output.
```

## Posting Cadence

- 3–4 feed posts per week
- Stories as needed for process/behind-the-scenes
- The Slow Clock applies from day one
- Do not batch-post
- No engagement hacking, no follow-for-follow, no hashtag gaming

## Engagement Rules

- Reply to thoughtful comments only
- No "thanks for following!" No emoji reactions to strangers
- If someone asks a real question, answer in the voice
- DMs: respond to serious inquiries only

## Content Mix (Instagram)

- 60% processed visual work (face grids, halftone, silhouettes)
- 20% wall texture / documentary photography
- 10% process documentation
- 10% text posts (manifesto-density lines on black ground)

## Masks Involved

- **Rupture Host** — aesthetic vision and narrative
- **Aesthetic Critic** — anti-generic filter
- **Night Witness** — ethical review for sensitive material
- **Ethicist** — red line enforcement
