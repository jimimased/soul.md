# inbox/playlists/

Place playlist files or .md files listing tracks and URLs.

## Format

```markdown
---
title: Playlist Name
platform: spotify / youtube / soundcloud / bandcamp / mixed
date_created: YYYY-MM-DD
mood: descriptive tag
notes: Why this collection matters
---

1. Artist - Track [URL]
2. Artist - Track [URL]
```

Default privacy level: `public`.
